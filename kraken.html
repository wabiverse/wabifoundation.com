Workspace

Panels.

Split the window into areas and arrange the panels you need. Each panel edits the same stage, so a change in one shows up everywhere else on the next frame.

Layout viewport

Transform gizmos, box and pixel-accurate picking, drag and drop asset placement, pie menus under the cursor.

Outliner

The prim hierarchy as it exists on the stage. Reparent, rename, toggle visibility, frame a selection.

Properties

Object, material, modifier and output properties. Native fields, sliders and color pickers, wired to USD attributes.

Asset browser

Browse a library of USD assets and drop them in as references. The stage stays composed rather than flattened.

Dope sheet & timeline

Scrub, set and move keys over time samples. Playback runs through the renderer you are already looking at.

Material preview

A shaderball lit by the scene's own environment, updating as you edit the material.

Geometry

Modeling and sculpting.

Non-destructive modifier stack

Deformers layer over plain USD mesh prims and evaluate on the GPU every frame. Reorder them, disable one or change a parameter; the source geometry is never touched. The stack is written into the stage, not into a sidecar file.

Sculpting in place

The sculpt tab works on the mesh you have selected, where it sits. There is no default sphere and no separate document: start from an empty viewport, add a mesh, and sculpt it inside the same scene you were laying out.

Touch

iPad and iPhone.

The viewport, gizmos and pie menus take multi-touch directly rather than treating a finger as a mouse. On iOS, Kraken registers as an editor for USD files, so a scene in the Files app opens into the viewport and stays editable in place.

Direct manipulation

Orbit, pan and zoom with two fingers, drag a gizmo handle with one. Nothing sits behind a modifier key a tablet does not have.

Pie menus

Radial menus open under the pointer or finger, so common commands do not need the menu bar.

Files app integration

USD files open in place from iCloud, a share sheet, or the app's own documents folder.

Build

Written in Swift.

Swift against OpenUSD, with LabFX for graphics and SwiftCrossUI for the interface. One codebase bundles for every platform through swift-bundler.

build and launch
# desktop
make run USD_SCENE=Scenes/SculptingShowcase.usda

# iPhone or iPad, over USB
make run PLATFORM=iOS DEVICE_ID=<device> CODESIGN_IDENTITY=<identity>

# just the app bundle, no launch
make bundle

Open a stage.

The Mac build is a drag into /Applications. Everything else builds from source.
